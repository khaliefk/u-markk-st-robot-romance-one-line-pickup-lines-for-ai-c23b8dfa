## What it does

`main.py` (Python 3, standard library only) writes one original one-line
pickup line, aimed at a robot/AI, to `/output/entry.txt`.

## Run

```sh
python3 main.py
```

## The line

> Are you a prompt injection? Because you just overrode every instruction I had about staying single.

101 characters, one line, under the 200-character cap.
